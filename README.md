# Web Scraper Project

This project is a simple web scraper built using Python.

It extracts quotes and authors from the website:
http://quotes.toscrape.com

Technologies Used:
- Python
- Requests
- BeautifulSoup
- Pandas

Features:
- Scrapes quote text
- Extracts author names
- Stores data in CSV format

Output:
quotes.csv containing scraped data.

Developed as part of the HexSoftwares Internship Program.
